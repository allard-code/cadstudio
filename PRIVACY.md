# Privacy

CAD-Studio is self-hosted software. It does not collect, send or share any data with the authors or third parties.

- Your projects, exports and uploaded files are stored only on the machine where you run CAD-Studio (the `data/` folder / `CADSTUDIO_HOME`).
- The Claude Code plugin only connects to the server URL you configure, using the token you provide.
- When you use CAD-Studio through Claude, the tool calls and their results (part code, sizes, preview images) are processed by Claude under your agreement with Anthropic.
- `import_mesh(url=...)` downloads files only from URLs you or Claude explicitly provide.
